# demo 功能实现说明书

## 一、实现目标
1. 新增 demo 模式，在运行 demo 模式时，系统自动运行游戏以展示游戏的玩法。
2. 系统逐一对所有游戏模式进行演示。
3. 在演示每一步时，在 ui 中 STATUS 栏中对规则或操作进行说明。
4. 演示过程中保持正常的渲染循环，用户可通过任何键盘输入随时中断并回到手动操作模式，并且要告诉用户“输入任意键终止演示“。
5. 不修改任何游戏的领域逻辑与胜负判定。
6. 剧本结束后还是回到四个空对局。

## 二、具体演示内容

### 2.1 PeaceGame
1. 轮流落子
2. 棋盘填满
3. 终局判定
*为了节省演示时间，可以省略许多棋步，直接演示棋盘填满的终局*

### 2.2 ReversiGame
1. 夹吃反转
2. 合法落子高亮
3. pass 机制
4. 比分变化
5. 因为双方都无合法落子的终局（为了节省演示时间，棋盘填满的终局就不展示了，可以显示一定的文字提示）

### 2.3 MineSweeper
1. 首开安全
2. 数字提示
3. 插旗、取消插旗
4. 胜利的终局，失败的终局（中间步可以省略）

### 2.4 ChessGame
1. 兵的直走/吃子
2. 马的日字
3. 象的斜线
4. 后的火力
5. 王的步，王车易位
6. 吃过路兵
7. 兵升变
8. 胜负判定
*演示完上述规则，可以演示四步杀这个经典的完整棋局*

## 三、具体实现
在实现 demo 功能时，需遵循以下规定
1. 不得破坏原有代码逻辑
2. 保证职责清晰，改动最小，选择合适的位置改动代码
