# Lab5：终端小游戏平台

这是一个基于 **Java + Maven + Lanterna** 的终端小游戏平台，当前支持 4 种游戏：

- `peace`：和平棋
- `reversi`：黑白棋 / 翻转棋
- `minesweeper`：扫雷
- `chess`：国际象棋

程序采用左-中-右三栏布局：

- 左侧：当前棋盘
- 中间：当前游戏状态、最近消息、命令提示
- 右侧：所有已创建的棋盘列表，并标明 `running` / `over`

---

## 1. 环境要求

- **JDK 16** 或更高版本
- **Maven**
- 支持图形窗口的桌面环境（程序会打开一个 Swing 终端窗口）

---

## 2. 运行方式

在项目根目录执行：

```bash
mvn -q exec:java
```

如果你想先编译再运行，也可以：

```bash
mvn -q -DskipTests compile
mvn -q exec:java
```

主入口类是 `com.gameplatform.Main`。

---

## 3. 项目概览

本项目使用 **SPI** 自动加载游戏插件：

- 入口通过 `ServiceLoader<GamePlugin>` 加载所有实现
- 默认会创建各插件声明为默认局的游戏
- 当前仓库中的 4 个插件都标记为默认游戏，因此启动后会自动创建 4 局

启动后默认进入第 1 局。

界面中：

- **左侧棋盘**：显示当前局的棋盘内容
- **中间状态栏**：显示当前游戏编号、当前回合、模式特有信息、最近消息、操作说明
- **右侧列表**：显示所有游戏局号、类型和状态

当前游戏结束后，状态栏仍会保留最终结束提示，不会被后续输入覆盖。

---

## 4. 输入方式

输入完成后按 **Enter** 提交，**Backspace** 删除字符。

### 4.1 坐标输入

支持以下坐标格式：

- `a1`
- `1a`

字母不区分大小写，例如 `A1` 也可以。

> 注意：如果输入的是纯数字，程序会优先把它当作“切换棋盘编号”，而不是坐标。

### 4.2 切换棋盘

支持以下格式：

- `2`
- `switch 2`
- `s 2`

### 4.3 新增游戏

直接输入游戏类型名即可新增一局：

- `peace`
- `reversi`
- `minesweeper`
- `chess`

新增后不会自动切换到新局，需要手动输入编号切换。

### 4.4 扫雷插旗

支持以下格式：

- `f a1`
- `flag a1`
- `f 1a`
- `flag 1a`

再次对同一格输入插旗命令可取消旗子。

### 4.5 黑白棋 pass

- `pass`

只有 `reversi` 支持 `pass`。
如果当前局还有合法落子，输入 `pass` 会提示不允许跳过。

### 4.6 退出程序

- `quit`

### 4.7 演示模式

- `demo`

`demo` 会依次自动演示各个游戏的预设步骤。
演示过程中按任意键可以中断并返回手动模式。

---

## 5. 游戏说明

## 5.1 `peace`：和平棋

这是一个最基础的轮流落子模式。

规则：

- 棋盘大小固定为 `8 x 8`
- 黑白双方轮流落子
- 只能下在空位上
- 不做翻子、不做合法性限制
- 棋盘被下满后结束

适合用来测试多局切换和最基础的落子流程。

---

## 5.2 `reversi`：黑白棋

这是标准的黑白棋模式。

规则：

- 棋盘大小固定为 `8 x 8`
- 初始棋盘中央会放置 4 个棋子
- 黑白双方轮流落子
- 只有能够翻转对方棋子的落子才算合法
- 程序会高亮显示当前可落子位置
- 当前玩家没有合法落子时，可以输入 `pass`
- 双方都没有合法落子，或者棋盘满了，游戏结束

结束后会显示：

- 最终比分
- 胜负结果

---

## 5.3 `minesweeper`：扫雷

扫雷模式的实现特点如下：

- 棋盘大小固定为 `8 x 8`
- 地雷数量固定为 `10`
- **首次翻开时才生成地雷**，并保证首次翻开位置不是雷
- 支持单格翻开，不会自动展开 0 周围区域
- 支持插旗 / 取消插旗

规则：

- 翻开到雷：立即失败并结束
- 翻开到非雷：显示相邻 8 格雷数
- 相邻雷数为 `0` 时显示 `.`
- 当所有非雷格都被翻开时，游戏胜利并结束
- 结束后该局不能继续操作，但仍然可以切换查看

棋盘符号说明：

- `#`：未翻开
- `F`：已插旗
- `*`：雷（踩雷后才显示）
- `.`：周围没有雷
- `1` ~ `8`：周围雷数

---

## 5.4 `chess`：国际象棋

国际象棋模式支持：

- 棋盘大小固定为 `8 x 8`
- 标准棋子初始布局
- 轮流走子
- 兵的双步、吃过路兵、升变
- 王车易位
- 合法性检查与将军判定

落子命令：

- `m e2 e4`
- `move e2 e4`
- 升变时可附加目标棋子：`q` / `r` / `b` / `n`

例如：

```text
m b2 c1 q
```

表示兵升变为后。

---

## 6. 多对局管理

程序支持同时维护多局游戏。

- 启动时默认创建 4 局默认游戏：`peace`、`reversi`、`minesweeper`、`chess`
- 输入游戏类型名可以继续新增同类或其他类型的局
- 切换棋盘时，当前局状态会完整保留
- 右侧列表会显示每一局的状态：
  - `running`
  - `over`

---

## 7. 常见提示

- 如果输入坐标格式不对，会提示格式错误
- 如果输入的棋盘编号不存在，会提示超出范围
- `pass` 只适用于 `reversi`
- 扫雷的插旗只能作用于未翻开格子
- 游戏结束后再次输入操作，只会提示该局已结束，不会覆盖原有结束信息
- `demo` 运行期间，任意键可中断演示并恢复手动操作
