# LAB5

## 一、前情提示

* 本次Lab5以Lab4为基础继续迭代；
* 本次新增 `chess` (国际象棋)游戏，进一步验证“小游戏平台”的可扩展性；
* 要求大家在开始之前首先人工分析需要修改哪些内容；

## 二、本次迭代目标

1. 在现有平台中新增 `chess` 模式，并可完整运行一局。
2. 保持多对局并行能力，支持运行时新增游戏并切换查看。
3. 维持统一输入方式与统一界面布局（左-中-右）。但需要修改每个小游戏对应的提示输入部分。
4. 再不破坏既有 `peace` 、 `reversi` 和 `minesweeper` 逻辑的前提下完成增量开发。
5. <mark>新增demo模式，在demo模式中系统会自动运行游戏以展示游戏的玩法。</mark>
6. <mark>重构代码框架，采用插件化架构：游戏大厅作为主程序，每个游戏独立封装为一个模块（Package）。游戏遵循统一接口标准，即可动态接入大厅，无需修改核心代码。</mark>

## 三、任务要求

### 1.新增Chess模式
* 棋盘大小固定为 `8 x 8` 。
* 国际象棋规则可参考 https://zh.chess.page/
* 行棋操作：输入 `m 1a 2a` 或 `move 1a 2a` 将一个棋子从一个目标格移动到另一个目标格。
* 对于不同的棋子，需要编写对应的行棋规则以确保其正确行棋。

### 2.国际象棋胜负规则
* 为简化判定与测试，本次lab中当一方的王棋**被吃掉**时，游戏立即结束，而非原版游戏中判定将死后结束。
* 结束后该局不可继续操作，但允许切换查看。

### 3.初始游戏列表
程序启动后默认存在4局：
1. 游戏1： `peace`
2. 游戏2： `reversi`
3. 游戏3： `minesweeper`
4. 游戏4： `chess`

默认进入游戏1。

### 4.多对局与动态新增
* 输入棋盘编号可切换对局，切换后状态必须完整保留。
* 运行中支持新增：
  * 输入 `peace` ：新增一局peace
  * 输入 `reversi` ：新增一局reversi
  * 输入 `minesweeper` ：新增一局minesweeper
  * 输入 `chess` ：新增一局chess
* 新增后不自动切换，需手动输入编号或使用快捷键切换。

### 5.输入约定
每回合输入应为以下之一：
* 移动棋子： `m 1a 2a` 、 `move 1a 2a`
* 棋盘切换： `2` 、 `5` 、 `switch 2` 、 `s 2`
* 新建游戏： `peace` / `reversi` / `minesweeper` / `chess`
* 退出程序： `quit`

对于每一种小游戏，布局右侧的 `Commands` 提示输入部分仅显示当前游戏可执行的操作与切换棋盘的操作。

### 6.界面打印要求
* 左侧：棋盘区域。
* 中间：当前游戏状态信息（游戏编号、玩家信息、模式特有状态、最近⼀条消息）。
* 右侧：游戏列表（编号+类型），并明确当前所在对局。
* 国际象棋模式图例：
  * `K (King)` 、 `Q (Queen)` 、 `R (Rook)` 、 `B (Bishop)` 、 `N (Knight)` 、 `P (Pawn)` ：黑棋棋子（使用大写英文首字母）
  * `k` 、 `q` 、 `r` 、 `b` 、 `n` 、 `p` ：白棋棋子（使用小写英文首字母）
  * `.` :空格
* 仅要求保持左-中-右相对布局，不要求与演示图像素级一致

### 7.各模式边界规则

#### Peace、reversi、Minesweeper
* 与Lab4相同

#### Chess
* 棋子需按行棋规则落子，一方王棋被吃掉时结束。

### 8.非法输入处理
* `chess` 模式中需要对任意棋子非法行棋时做出提示。
* 其余与Lab4中一致。

### 9.demo模式
* demo模式中，系统可根据程序设定，自行运行游戏以展示游戏内容

## 四、运行示例

### 1.初始启动
* 默认展示四局：peace/reversi/minesweeper/chess
* 当前在游戏1，可通过编号或快捷键切换。

### 2.切换到国际象棋
* 输入 `4` （或 `s 4` ）切换到游戏4
* 棋盘初始应为国际象棋的初始状态，并给出一定的图例区分黑棋和白棋。

### 3.国际象棋基础操作
* 输入 `m 7a 5a` 让 `7a` 的 `p` 移动到 `5a` 。
* 交换行棋权
* 输入 `m 1b 3c` 让 `1b` 的 `N` 移动到 `3c` 。
* 国际象棋中的王车易位、吃过路兵、兵升变等规则均需正常实现。
* 对和棋规则不要求实现。

### 4.对局结束
* 当一方王棋**被吃掉**时游戏结束，显示胜利方并结束此局。
* 结束后继续输入 `move` 指令，应提示"该局已结束"

### 5.继续操作
与Lab4要求相同

### 6.demo模式
* 系统逐一对所有游戏模式进行自动演示。
